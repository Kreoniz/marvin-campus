# Кампус

Сравнение расписаний ОмГТУ: свободные окна, общее присутствие и совместные занятия.
React 19, TypeScript, TanStack Query, Vite, Tailwind CSS и unlikely-ui; Go API с SQLite-кэшем.

Сайт: [campus.kreoniz.ru](https://campus.kreoniz.ru).

## Запуск

Нужны Go 1.27, Node.js 26 и pnpm 12.5.1.

```sh
pnpm install --frozen-lockfile
go mod download
go run ./cmd/campus
```

Во втором терминале запустить `pnpm dev`, открыть `http://localhost:5173`.
Vite проксирует `/api` на Go (`:8080`). После `pnpm build` Go отдаёт готовый
клиент из `dist`. Доступ к источнику зависит от его доступности; при необходимости
Go поддерживает стандартный `HTTPS_PROXY`.
Для отдельного API при разработке можно задать `CAMPUS_API_ORIGIN`, например
`CAMPUS_API_ORIGIN=http://127.0.0.1:8086 pnpm dev --port 5175`.

```sh
pnpm check
pnpm lint
pnpm format:check
pnpm test
pnpm build
go test -race ./...
go vet ./...
```

Код проверяет Oxlint со встроенными правилами React Hooks и JSX accessibility;
проверка типов остаётся отдельной командой `pnpm check` (TypeScript).
`pnpm lint:fix` применяет безопасные исправления линтера, `pnpm format` форматирует
код через Oxfmt. Экспериментальные правила React Compiler отключены: компилятор
не включён в сборку. Правила доступности допускают управление начальным фокусом
внутри DS-компонентов и `tabIndex` у именованных областей прокрутки (`role="region"`);
они не заменяют проверку интерфейса клавиатурой и в браузере.

## Контейнер

```sh
docker compose up --build -d
```

Пример Compose публикует приложение только на `127.0.0.1:8080`; внешний HTTPS
можно настроить своим reverse proxy. Том SQLite сохраняется между обновлениями.
Контейнер работает без root, с read-only filesystem и без Linux capabilities.

Настройки: `LISTEN_ADDR` (`:8080`), `CACHE_PATH` (`./data/campus.sqlite`),
`STATIC_DIR` (`./dist`), `UPSTREAM_URL` (`https://rasp.omgtu.ru`),
`UMAMI_WEBSITE_ID` (пустой по умолчанию), `TRUSTED_PROXY_CIDRS` (пустой).
Последнее поле — список CIDR доверенных reverse proxy через запятую. Без него
заголовки forwarded IP игнорируются. Не доверяйте всем адресам: иначе клиент
сможет обходить ограничения, подставляя чужой IP.

## Данные и ссылки

Текущая неделя кешируется на 30 минут, будущая — на час, прошлая — на сутки;
поиск групп — на сутки. Повторные запросы объединяются, очередь ограничена.
Есть защита от частых запросов и сохранённые снимки при недоступности источника.
Ошибки не считаются пустым расписанием. Ручного обновления источника нет.

Пример ссылки: `/fit-232-s2+ivt-233?d=2026-10-18&v=free`. Группы, порядок,
подгруппы, день и режим хранятся в URL; сервер не создаёт новую запись сравнения.
Транслитерация обратима: неоднозначные буквы разделяются, обычные коды остаются
короткими. Формат один, без параметра версии. Старые `/s/id` доступны для чтения;
создание через `POST /api/share` отвечает 410.

PWA устанавливается через меню браузера. Офлайн доступны приложение и недавно
открытые расписания в пределах срока хранения. Обновление приложения сохраняет
выбор, а срок свежести расписания не продлевается при чтении кеша.
При повторном открытии сохранённые занятия видны до завершения запроса;
состояние данных и подробности ошибок доступны в строке над расписанием.

На кнопках дней работают ←/→, Home/End и Page Up/Page Down; на выборе недели —
также ←/→. Vim-шорткаты: h/l — день, Shift+h/l — неделя, j/k — прокрутка,
gg/Shift+g — края календаря, t — сегодня, / — поиск, 1/2/3 — день/неделя/список,
? — справка. Работают и в русской раскладке; отключаются в «Отображение».
Команды не мешают вводу текста и открытым окнам.

День, Неделя и Список переключаются в шапке; подробности под Неделей всегда
показаны шкалой. Календари используют вертикальную прокрутку страницы и
горизонтальную прокрутку дорожек. В Дне выбор «К расписанию» переносит к нужному
источнику. «Сегодня» раскрывает нужный столбец и при повторном нажатии, сохраняя
историю только для изменения даты.

Меню компактной плашки открывает подгруппы, подсветку и управление выбранными.
Можно подсветить несколько расписаний; состояние видно по заливке без галочек.
В управлении порядок меняется перетаскиванием, кнопками выше/ниже или Alt+↑/↓.
Завершённое перетаскивание создаёт один переход в истории; отмена сохраняет порядок.

Локальные документы ВУЦ сохраняют исходные даты. При настроенном
`VUC_ORIGINALS_DIR` доступно одно «Скачать» на документ с проверенными байтами
PDF/DOCX; отсутствующий оригинал обозначен явно. Текущий семестр обновляется
без агента: `python3 scripts/update-vuc.py examples/current-semester.docx --output-dir .local/vuc/sets/semester-next`.
Команда готовит новый набор и оригиналы, сохраняя прежний; оператор переключает
оба пути и перезапускает API. Полный порядок и настройка описаны в
[документации ВУЦ](docs/vuc.md).

## Документация

Релизы используют [SemVer](https://semver.org/lang/ru/): версия в `package.json`,
тег `vX.Y.Z` и одноимённый GitHub Release относятся к одному коммиту.
До 1.0 новые возможности и изменения контрактов увеличивают минорную версию,
совместимые исправления — патч. Совместимость оцениваем по HTTP API и сохранённым
ссылкам на сравнения; изменения контрактов описываем в примечаниях к релизу.
Образ привязан к полному SHA коммита и содержит OCI-метку версии; опубликованные
версии и теги не переназначаем.
