# Локальные документы ВУЦ

Расписания ВУЦ можно импортировать из датированных PDF и DOCX и выбрать взвод
через общий поиск. Это локальная копия документа, а не синхронизация с сайтом ВУЦ.
Даты документа сохраняются: расписание за прошлый год не переносится на текущий.

Импорт выполняется до запуска сервера. Публичного загрузчика файлов нет.
DOCX читается стандартной библиотекой Python; для PDF в инструментальном
окружении нужен `pdfplumber`. Это зависимость импортера, не приложения.

```sh
uv run --with pdfplumber python scripts/import-vuc.py examples/monday.pdf examples/thursday.docx --out .local/vuc/schedules.json
VUC_DATA_PATH=.local/vuc/schedules.json mise exec -- go run ./cmd/campus
```

Оригиналы и полученный JSON остаются вне Git. Каталог `.local/vuc/` игнорируется.
Сервер читает только путь из `VUC_DATA_PATH` при запуске; после замены файла его
нужно перезапустить. Пустой путь отключает источник. Повреждённый или слишком
большой файл не превращается в пустое расписание: сервер сообщает об ошибке.

## Правила импорта

Импортер сохраняет период каждого раздела, исходную дату, подпись взвода,
хеш документа, положение ячейки, оригинальный текст и напечатанные интервалы.
Для DOCX учитываются единицы сетки таблицы и ширина ячеек заголовка: `gridSpan`
не означает число пар. Для PDF используется геометрия таблицы. Поддерживаются
повторные заголовки и продолжение таблицы на следующей странице.

Объединённая ячейка показывается от начала первого до конца последнего
напечатанного интервала. Если между ними есть перерывы, их занятость не
предполагается: соответствующий день помечается как требующий проверки и
не участвует в расчёте общих окон. Исходные интервалы остаются в данных.

Если граница ячейки проходит внутри заголовка времени, точное время не
вычисляется. Текст остаётся в `unparsedCells` с причиной и местом в документе.
Несовпадение даты и подписи дня недели также сохраняется с предупреждением.
Импортер не исправляет дату автоматически.

Покрытие хранится отдельно для каждого взвода и даты. `coveredDates` содержит
однозначно разобранные строки, `unresolvedDates` — известные строки с неоднозначностью.
Отсутствующая строка означает «нет данных», а не свободный день. Известные пары
из неоднозначного дня можно показать, но нельзя считать его полным для расчёта.
Преподаватели и помещения из документов остаются текстом: совпадение фамилии
или номера кабинета не создаёт ссылку на сущность основного расписания.

## API и проверка

- `GET /api/vuc?term=...` — взводы и их разрешённые даты. Пустой запрос возвращает
  небольшой локальный каталог; длина запроса ограничена 80 символами.
- `GET /api/vuc/{id}?week=YYYY-MM-DD` — пары, покрытие, неподдающиеся разбору
  ячейки и предупреждения запрошенной недели. Неделя начинается с понедельника.
- Отключённый источник отвечает 503, неизвестный взвод — 404. Ответ без покрытия
  на выбранную дату не устанавливает отсутствие занятий.

Ответы помечены как локальные сохранённые данные. `importedAt` относится к
импорту документа; `checkedAt` HTTP-ответа не подтверждает актуальность сайта.
JSON ограничен 8 МиБ, число расписаний — 100, общее число пар — 20 000.
Входной документ ограничен 16 МиБ; PDF — 30 страницами.

```sh
python3 -m unittest discover -s scripts -p 'test_import_vuc.py'
mise exec -- go test -race ./internal/vuc ./internal/httpapi
```

Перед использованием нового источника следует проверить несколько одиночных
и объединённых ячеек по исходным страницам. Неоднозначные строки требуют
проверки документа; успешный импорт не устраняет ошибки его составителя.

## Страница ВУЦ и подробности военной подготовки

`/vuc` — отдельный календарь только для расписаний ВУЦ. Каталог показывает
период источника рядом с короткой подписью «ВУЦ 101». Можно выбрать несколько
документов, переключать День/Неделю/Список и скопировать ссылку с выбором и датой.
История и сохранённый выбор раздела отделены от основного календаря.

В подробностях академического занятия «Военная подготовка» есть выбор
«Моё расписание ВУЦ». Он запоминает личное предпочтение для просмотра и показывает
занятия на ту же дату, не добавляя нового участника в основной расчёт. Связь
учебной группы и ВУЦ не угадывается. Ссылка рядом открывает выбранное расписание
на отдельной странице; при отсутствии покрытия доступен переход к ближайшей
подтверждённой дате. Неоднозначность, период документа, исходные интервалы и
недоступность источника остаются явными.

В «Списке» то же личное расписание доступно через закрытое раскрытие у военной подготовки. Высокая карточка показывает ограниченное число записей; статус документа и число оставшихся записей видны перед ними, полные напечатанные интервалы — в подробностях. При одинаковых номерах взводов из разных документов навигация, управление и состав расчёта добавляют год и при необходимости подпись источника.
