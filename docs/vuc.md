# Локальные документы ВУЦ

Расписания ВУЦ можно импортировать из датированных PDF и DOCX и выбрать взвод
через общий поиск. Это локальная копия документа, а не синхронизация с сайтом ВУЦ.
Даты документа сохраняются: расписание за прошлый год не переносится на текущий.

## Обновление текущего семестра

Основной каталог ВУЦ содержит **явно выбранный набор текущего семестра**.
Обычно это один выданный PDF или DOCX; несколько файлов нужны только тогда,
когда они вместе составляют этот набор. Старый PDF не следует добавлять рядом
с новым DOCX лишь потому, что оба файла лежат на диске. Семестр, год и даты
не определяются по имени файла, времени изменения или сегодняшнему дню.

Подготовка выполняется оператором до запуска API. Агент, публичный загрузчик,
автоматическое скачивание и горячая замена не нужны. DOCX читается стандартной
библиотекой Python; для PDF нужен `pdfplumber` в отдельном инструментальном
окружении. Это зависимость импортера, не приложения.

1. Сохраните полученный документ и явно перечислите **все** входы нового набора.
   Укажите новый каталог результата, который ещё не существует:

   ```sh
   python3 scripts/update-vuc.py examples/current-semester.docx --output-dir .local/vuc/sets/semester-next
   ```

   Для PDF или смешанного набора команда та же, с инструментальным окружением:

   ```sh
   uv run --with pdfplumber python scripts/update-vuc.py examples/current-semester.pdf --output-dir .local/vuc/sets/semester-next
   ```

   Команда создаёт `schedules.json` и `originals/<полный SHA-256>.pdf`/`.docx`.
   Она сначала фиксирует точные байты входов, затем импортирует эти копии и
   публикует готовый каталог одним переименованием. Повтор одного файла
   дедуплицируется. Существующий каталог результата не перезаписывается;
   ошибка не оставляет частичный новый набор. Другие документы и прежний набор
   не читаются и не удаляются. Для следующего обновления выберите другой новый путь.

2. Сверьте период, несколько одиночных и объединённых ячеек, предупреждения и
   даты по оригиналу. Успешный импорт не исправляет неоднозначности документа.

3. В настройках запуска API укажите **оба пути из одного подготовленного набора**:

   ```sh
   VUC_DATA_PATH=.local/vuc/sets/semester-next/schedules.json VUC_ORIGINALS_DIR=.local/vuc/sets/semester-next/originals mise exec -- go run ./cmd/campus
   ```

   Для работающего сервера сначала измените его настройки запуска, затем
   выполните обычный контролируемый перезапуск API. Скрипт сам не меняет настройки,
   живые данные или процесс. API читает набор и оригиналы только при старте.
   При откате верните оба прежних пути и перезапустите API тем же способом.

Исходные файлы, наборы и JSON остаются вне Git; `.local/vuc/` игнорируется.
Сохранённые URL старых взводов не переназначаются новым документам: после смены
набора старый ID может стать недоступным. Он не означает пустое расписание.
В личном выборе предпросмотра доступны только взводы пригодного активного каталога;
недоступный сохранённый выбор требует явного выбора другого расписания.

Низкоуровневый `scripts/import-vuc.py INPUT... --out FILE` по-прежнему доступен
для импорта одного явно перечисленного набора в JSON и атомарно заменяет только
этот файл. Для обычного обновления используйте `update-vuc.py`, чтобы согласованно
подготовить JSON и оригиналы. Пустой `VUC_DATA_PATH` отключает источник.
Повреждённый или слишком большой JSON не превращается в пустое расписание:
сервер сообщает об ошибке.

## Скачивание оригиналов

`VUC_ORIGINALS_DIR` включает скачивание проверенных исходных байтов. Скрипт
обновления уже копирует файлы с нужными хеш-именами, не меняя их содержимое.
Сервер разрешает только полные хеши документов из настроенного набора, обычные
PDF/DOCX до 16 МиБ каждый и до 64 МиБ суммарно; символические ссылки не
поддерживаются. При запуске проверяются SHA-256 и формат. Проверенные байты
хранятся в памяти один раз на документ; другие файлы каталога не публикуются.
Файловые пути не принимаются из HTTP-запроса.

Пустой `VUC_ORIGINALS_DIR` отключает скачивание, сохраняя расписание.
Отсутствующий оригинал также не мешает показывать расписание:
`originalAvailable: false` (в старых ответах поле может отсутствовать).
Повреждённый файл с разрешённым именем или неверный настроенный каталог
останавливает запуск с ошибкой. `originalAvailable: true` появляется в каталоге
и неделе только после проверки оригинала.

В футере показано одно «Скачать» на исходный документ независимо от числа
выбранных взводов. Недоступность обозначается «Оригинал недоступен»; доступность
не зависит от покрытия выбранной даты. Старые метаданные сохранённого выбора
или недели не подтверждают скачивание: нужен пригодный текущий каталог с этим ID
и явным `originalAvailable: true`. При ошибке или истечении срока хранения каталога
ссылка не обещает доступность файла.

## Правила импорта

Импортер сохраняет период каждого раздела, исходную дату, подпись взвода,
хеш документа, положение ячейки, оригинальный текст и напечатанные интервалы.
Для DOCX учитываются единицы сетки таблицы и ширина ячеек заголовка: `gridSpan`
не означает число пар. Для PDF используется геометрия таблицы. Поддерживаются
повторные заголовки и продолжение таблицы на следующей странице.

Объединённая ячейка показывается от начала первого до конца последнего
напечатанного интервала. Если между ними есть перерывы, их занятость не
предполагается: соответствующий день помечается как требующий проверки и
не участвует в расчёте общих окон. Исходные интервалы остаются в данных.

Если граница ячейки проходит внутри заголовка времени, точное время не
вычисляется. Текст остаётся в `unparsedCells` с причиной и местом в документе.
Несовпадение даты и подписи дня недели также сохраняется с предупреждением.
Импортер не исправляет дату автоматически.

Покрытие хранится отдельно для каждого взвода и даты. `coveredDates` содержит
однозначно разобранные строки, `unresolvedDates` — известные строки с неоднозначностью.
Отсутствующая строка означает «нет данных», а не свободный день. Известные пары
из неоднозначного дня можно показать, но нельзя считать его полным для расчёта.
Преподаватели и помещения из документов остаются текстом: совпадение фамилии
или номера кабинета не создаёт ссылку на сущность основного расписания.

## API и проверка

- `GET /api/vuc?term=...` — взводы и их разрешённые даты. Пустой запрос возвращает
  небольшой локальный каталог; длина запроса ограничена 80 символами.
- `GET /api/vuc/{id}?week=YYYY-MM-DD` — пары, покрытие, неподдающиеся разбору
  ячейки и предупреждения запрошенной недели. Неделя начинается с понедельника.
- `GET /api/vuc/{id}/original` — исходные байты PDF/DOCX для канонического ID
  взвода. Ответ имеет соответствующий `Content-Type`, `Content-Disposition:
  attachment`, `nosniff` и `Cache-Control: no-store`; поддерживаются HEAD и Range.
  Без оригинала или при неизвестном ID — 404, при неверном ID — 400,
  при отключённом наборе ВУЦ — 503. Скачивание не требует покрытия выбранной даты.
- Отключённый источник отвечает 503, неизвестный взвод — 404. Ответ без покрытия
  на выбранную дату не устанавливает отсутствие занятий.

Ответы помечены как локальные сохранённые данные. `importedAt` относится к
импорту документа; `checkedAt` HTTP-ответа не подтверждает актуальность сайта.
JSON ограничен 8 МиБ, число расписаний — 100, общее число пар — 20 000.
Входной документ ограничен 16 МиБ; PDF — 30 страницами.

```sh
python3 -m unittest discover -s scripts -p 'test_*vuc.py'
mise exec -- go test -race ./internal/vuc ./internal/httpapi
```

Перед использованием нового источника следует проверить несколько одиночных
и объединённых ячеек по исходным страницам. Неоднозначные строки требуют
проверки документа; успешный импорт не устраняет ошибки его составителя.

## Страница ВУЦ и подробности военной подготовки

`/vuc` — отдельный календарь только для расписаний ВУЦ. Каталог показывает
период источника рядом с короткой подписью «ВУЦ 101». Можно выбрать несколько
взводов текущего набора, переключать День/Неделю/Список и скопировать ссылку с выбором и датой.
История и сохранённый выбор раздела отделены от основного календаря.

В подробностях академического занятия «Военная подготовка» есть выбор
«Расписание ВУЦ». Он запоминает личное предпочтение для просмотра и показывает
занятия на ту же дату, не добавляя нового участника в основной расчёт. Связь
учебной группы и ВУЦ не угадывается. Ссылка рядом открывает выбранное расписание
на отдельной странице; при отсутствии покрытия доступен переход к ближайшей
подтверждённой дате. Неоднозначность и отсутствие покрытия остаются явными в состоянии данных и
пояснениях расчёта. Период, предупреждения и неподдающиеся разбору ячейки доступны
в «Примечаниях документа» внутри состояния данных каждого взвода. Исходный текст
и напечатанные интервалы каждой известной пары остаются в её «Строке документа».

В «Списке» то же личное расписание доступно через закрытое раскрытие у военной
подготовки. Высокая карточка показывает ограниченное число записей, включая
преподавателей, когда они помещаются; статус документа и число оставшихся записей
остаются видимыми. Все напечатанные интервалы доступны в закрытом по умолчанию
раскрытии «Все занятия на этот день» в подробностях.

Доступный оригинал скачивается действием «Скачать» из футера или предпросмотра;
при отсутствии файла интерфейс сообщает об этом явно. Доступность оригинала
не зависит от покрытия выбранного дня. Статичные карточки документа не пульсируют,
а неизвестный вид занятия не обозначается знаком вопроса.

При одинаковых номерах взводов из разных документов навигация, управление и состав
расчёта добавляют год и при необходимости подпись источника.
