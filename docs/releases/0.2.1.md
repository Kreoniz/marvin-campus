# Кампус 0.2.1

Source release prepared on 2026-10-31. Actual activation evidence belongs in
[the deployment runbook](../deployment.md).

- Upgrade exact unlikely-ui from `0.1.0-alpha.2` to `0.1.0-alpha.3`.
  Existing Russian dialog close controls remain the only close buttons, and
  Theme explicitly forwards Russian language metadata to built-in portals.
  The custom bare Combobox input and app-owned Omsk date policy are preserved.
- Adopt focused testing rules in `AGENTS.md`, separating ordinary validation
  from full CI/release checks. Remove eight redundant test cases, retain unique
  URL validation in its owning suite and test layout behavior without copying
  implementation formulas or freezing incidental pixel values.

See [the actual-app alpha.3 verification](../reviews/2026-10-31-unlikely-ui-alpha3.md)
and [the testing policy assessment](../reviews/2026-10-31-testing-policy.md).
The HTTP API, saved comparisons, database and document format contracts are
unchanged. Current VUC documents remain configured outside the image and Git.
