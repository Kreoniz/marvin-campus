# Кампус 0.2.2

Source release prepared on 2026-10-31. Actual activation evidence belongs in
[the deployment runbook](../deployment.md).

Schedule spotlights now survive page reloads and reopening the app in the same
browser. General and VUC workspaces keep independent local preferences using
typed schedule identities. Clearing highlights and removing a selected schedule
update the saved preference; opening a link or restoring a workspace cannot
erase highlights while selection resolution is still pending.

The existing fewer-than-two-selections clearing rule is retained. Highlighting
does not enter shared URLs or calculations. Corrupt or unavailable browser
storage falls back safely to in-memory interaction.

The original reload failure was reproduced before the fix. Two focused storage
tests and nine app browser scenarios cover reloads, delayed link resolution,
implicit workspace restoration, date/order changes, removal, clearing, separate
VUC preferences, 320px layouts and unavailable storage. Browser verification
used isolated Chromium with neutral HTTP fixtures, not a live university source.
