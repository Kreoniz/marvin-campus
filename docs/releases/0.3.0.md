# Кампус 0.3.0

Source release prepared on 2026-11-02. Actual activation evidence belongs in
[the deployment runbook](../deployment.md).

Saved subgroup identities are resolved against the current response before
comparison. Obsolete or ambiguous IDs cannot create confident free windows.
The VUC importer accepts dotted dates and rejects unrecognized nonempty date
cells instead of attaching them to the preceding date.

Opening another comparison preserves the saved workspace and highlights.
Intentional selection edits adopt the viewed set; date, mode and history changes
do not. Repeating active navigation adds no duplicate history entry.

The existing offline cache now supports group, lecturer, auditorium and VUC weeks,
with actual per-source availability, shared validation and unchanged observation
timestamps. Delayed writes preserve newer observations, independent saved-data
expiry remains visible, and one preceding activated build can supply old hashed
assets across an update or rollback.

Day/Week/List is remembered separately for each workspace. Empty Day is compact
without confusing hidden, saved or unavailable data with an empty timetable.
Subgroup shorthand confirms the complete name, unique base and selected-week
catalogue before offering a choice. VUC status distinguishes import time from
live/server checks. One personal schedule on Omsk today can show current/next
lessons, including simultaneous lessons and saved/document qualifications.

One council code-review round used two Terra and two Sol reviewers. All actionable
findings were resolved with targeted validation; scores refer to the pre-fix
revision. See [the implementation and review record](../reviews/2026-11-02-issue-5-code-council.md).

Static component rendering and worker VM tests do not establish native browser
Back/Forward, focus, offline relaunch, two-tab activation or physical-device
behavior. Those checks remain open. Lane-width alternatives, resource-action
usability and client render profiling remain investigations; no speculative
server refresh or search-ownership redesign is included.
