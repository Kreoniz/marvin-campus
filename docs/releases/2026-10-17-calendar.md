## Data and activation

A consistent SQLite backup and the previous environment/image were retained
before activation. SQLite integrity checks passed. All 108 legacy link records
retained their exact IDs, payloads and creation times. The existing volume,
private Compose, Caddy configuration and environment values other than the
image selection were preserved. Backend admission controls and proxy policy
were not changed.

The first activation passed health and HTTPS checks, then automatically rolled
back because a deployment assertion expected an active cache row's bytes and
timestamps to stay fixed. Its ordinary source refresh changed timestamps and
the ordering of simultaneous events. Comparing the original backup, live row
and freshly normalized university response confirmed identical lesson and
subgroup content with the correct one-hour future-week lifetime. The assertion
was corrected to compare content independently of array order and allow valid
refresh timestamps; the application code and image did not change. The second
activation passed health, integrity, content and configuration checks.

The previous image remains available for rollback. Existing installed PWA
clients receive the application update through their usual “Обновить” action;
the update preserves the selected groups, subgroup, date and theme.
