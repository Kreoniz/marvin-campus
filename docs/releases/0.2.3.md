# Кампус 0.2.3

Source release prepared on 2026-10-31. Actual activation evidence belongs in
[the deployment runbook](../deployment.md).

The compact header is now sticky at the viewport edge with an opaque background
matching the current theme. It provides a solid boundary between the controls
and native mobile scroll-edge effects. The Day source chooser sticks below the
app header; keyboard scrolling reserves room for the header. Desktop header
positioning and horizontal schedule scrolling are retained.

Before/after captures and focused Chromium checks covered 320px light, 390px
dark and desktop layouts, page and selection-strip scrolling, theme changes,
settings layering, Escape/focus return, schedule menus and Day/Week switching.
Neutral local HTTP fixtures were used. No permanent pixel-value test was added.

The reported iPhone blur could not be reproduced in desktop Chromium. The
native Safari scroll-edge effect is the suspected cause, rather than a verified
CSS blur in the app. Physical iPhone/PWA verification remains outstanding.
Local WebKit could not launch because its required `libicudata.so.74` is absent;
no WebKit compatibility result is claimed.
